プライバシーポリシー

サクッと国会ニュース運営事務局（以下「当運営」）は、当サイトおよびYouTubeチャンネル「サクッと国会ニュース」の運営にあたり、個人情報を次のとおり取り扱います。

1. 取得する情報

お問い合わせフォーム（Google フォーム）から、次の情報をお預かりします。

  • お名前（ニックネーム可）
  • メールアドレス
  • お問い合わせの種類・内容、対象の動画やページのURL

当サイトでは、アクセス解析ツールや広告のためのCookieは使用していません。

2. 利用目的

  • お問い合わせへの回答、ご依頼内容の確認・対応のため
  • 動画・サイトの訂正・削除等の対応のため

上記の目的以外には利用しません。

3. 第三者への提供

法令に基づく場合を除き、ご本人の同意なく個人情報を第三者に提供することはありません。なお、お問い合わせフォームは Google LLC が提供する Google フォームを使用しており、入力された情報は Google のサービス上に保存されます（Google プライバシーポリシー）。

4. 安全管理

お預かりした個人情報は、閲覧できる者を当運営の担当者に限るなど、漏えい・滅失等を防ぐために必要な管理を行います。対応が終わった情報は、必要な期間を過ぎたあと削除します。

5. 開示・訂正・削除等について

ご本人から、ご自身の個人情報の開示・訂正・利用停止・削除等のご請求があった場合は、ご本人であることを確認のうえ、法令に従って対応いたします。お問い合わせフォームからご連絡ください。

6. 動画投稿用ツールにおける Google ユーザーデータの取り扱い

当運営は、制作した動画を当チャンネルへ投稿するため、YouTube Data API を使う投稿用ツール（以下「本ツール」）を運用しています。本ツールは当運営だけが使うもので、一般の方に提供するものではありません。

  • 本ツールが使う権限は、当運営自身の YouTube チャンネルへの動画のアップロード、タイトル・概要欄・サムネイルの設定、投稿先チャンネル名の確認に限られます。
  • 視聴者の方の個人情報を取得することはありません。
  • 認証の情報（アクセス用のトークン）は当運営のパソコン内にのみ保存し、外部へ送信したり、第三者に提供・販売したりすることはありません。
  • 本ツールによる Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。YouTube の利用には YouTube 利用規約 が適用されます。
  • 本ツールに与えた権限は、Google アカウントのセキュリティ設定からいつでも取り消せます。

7. お問い合わせ窓口

個人情報の取り扱いに関するお問い合わせは、お問い合わせフォームからお願いします。

8. プライバシーポリシーの変更

本ポリシーの内容は、必要に応じて変更することがあります。変更後の内容は、当ページに掲載した時点から効力を生じます。
